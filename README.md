# 💰 Expense Tracker

A simple Expense Tracker application developed using Python. This project helps users record, manage, and monitor their daily expenses efficiently through an easy-to-use interface.

---

## 📌 Project Overview

This project was developed as part of the **DecodeLabs Industrial Training Program**. It demonstrates Python programming concepts such as variables, functions, lists, loops, conditional statements, and user input while solving a real-world expense management problem.

---

## ✨ Features

- ➕ Add new expenses
- 📋 View all expenses
- ✏️ Update expense details
- ❌ Delete expenses
- 💵 Calculate total expenses
- 📊 Simple and user-friendly interface

---


